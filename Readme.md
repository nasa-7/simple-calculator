# Simple Calculator
## Purpose
A command-line calculator written in Python. Final project for Software Maintenance (Lab 7), built with Git branches and pull requests.
## Key Features
-	Addition, subtraction, multiplication, division
-	Power (`**`) and modulus (`%`)
-	Division-by-zero protection
-	Input validation (the program never crashes on bad input)
-	Calculation history saved to `history.txt` (type `h`)
## How to Run     python calculator.py Example: choose `**`, enter `2` and `3`, and the result is `8.0`.
